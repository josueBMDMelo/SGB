4??  POR QUE FUNCIONA?
???????????????????????????????????????????????????????????????????????????????

A lógica funciona porque:

1. SessaoUsuario.Perfil é preenchido quando o usuário faz LOGIN
   ?? Vem do banco de dados (tabela Usuarios, coluna Perfil)

2. Os perfis existentes são EXATAMENTE 3:
   ?? "Usuario"
   ?? "Bibliotecario"
   ?? "Administrador"

3. A validação é feita no evento LOAD do formulário
   ?? Antes de carregar qualquer dado
   ?? Antes do usuário conseguir fazer nada

4. Se não tiver permissão:
   ?? Mostra mensagem de erro
   ?? Fecha o formulário
   ?? Não continua executando o código

5. Se tiver permissão (é Admin):
   ?? Continua normalmente e carrega os dados

8??  POR QUE É UMA LÓGICA VÁLIDA?
???????????????????????????????????????????????????????????????????????????????

? É SIMPLES
   ?? Código direto, sem complexidade desnecessária

? É CONFIÁVEL
   ?? Dados vêm do BD (não podem ser falsificados pelo usuário)
   ?? Validação acontece ANTES de carregar dados

? É SEGURA
   ?? Bloqueia no código (não apenas na UI)
   ?? Funciona mesmo se usuário tentar contornar o menu

? É RÁPIDA
   ?? Apenas uma string comparison
   ?? Executa instantaneamente

? É CLARA
   ?? Qualquer desenvolvedor entende imediatamente
   ?? Não precisa de explicação complexa

? É REUTILIZÁVEL
   ?? Pode usar o mesmo padrão em todos os formulários
   ?? Manutenção fica fácil

E se o usuário conseguisse fazer login com perfil errado no BD?
???????????????????????????????????????????????????????????????
Impossível! Porque:

1. No BD, Perfil tem CHECK constraint:
   CONSTRAINT CK_Usuarios_Perfil 
   CHECK (Perfil IN ('Usuario', 'Bibliotecario', 'Administrador'))

2. BD rejeita qualquer outro valor
3. Então SessaoUsuario.Perfil nunca pode ser inválido

? A LÓGICA É VÁLIDA PORQUE:

1. Dados vêm do BD (confiável)
2. Validação acontece no Load (cedo)
3. Se não tiver permissão, bloqueia tudo
4. Se tiver permissão, deixa passar
5. É simples, rápido e seguro
6. Padrão já usado em outros formulários (FrmReservaEspaco.cs)

private void FrmCadastroUsuario_Load(object sender, EventArgs e)
{
    // Apenas Admin pode gerenciar usuários
    if (SessaoUsuario.Perfil is not "Administrador")
    {
        MessageBox.Show(
            "Você não tem permissão para acessar esta funcionalidade!",
            "Acesso negado",
            MessageBoxButtons.OK,
            MessageBoxIcon.Warning);
        this.Close();
        return;
    }

    // Só chega aqui se for Admin
    CarregarUsuarios();
    ConfigurarCombos();
}
