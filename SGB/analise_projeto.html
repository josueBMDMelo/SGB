📋 O Que É o Projeto?

SGB (Sistema de Gestão de Biblioteca) é uma aplicação Windows Desktop desenvolvida em .NET 9 com Windows Forms que gerencia todas as operações de uma biblioteca. O sistema permite o controle de empréstimos, devoluções, reservas de espaços e cadastros de usuários, livros e exemplares com controle de acesso baseado em perfis de usuário.

🎯 Objetivo Principal

Automatizar e gerenciar os processos de uma biblioteca, incluindo:

  • Controle de empréstimos e devoluções de livros
  • Cadastro e gerenciamento de usuários, livros e exemplares
  • Reserva de espaços (salas de estudo)
  • Geração de multas por atraso
  • Controle de permissões por perfil de usuário

🏗️ Arquitetura e Tecnologia

Stack Tecnológico

.NET 9.0 Windows Forms SQL Server C# 12 BCrypt Microsoft.Data.SqlClient

Padrão Arquitetural

Camadas: O projeto segue uma arquitetura simples com separação entre:

  • UI (Presentation): Formulários Windows Forms (FrmXxx.cs)
  • Data Access: Classes de conexão e gerenciamento de banco (ConexaoBanco.cs)
  • Business Logic: Lógica distribuída nos formulários
  • Database: SQL Server com schema predefinido

⚙️ Funcionalidades Principais

1. Autenticação e Autorização

Sistema de Login: Validação com email e senha criptografada em BCrypt. Três perfis de acesso: Usuário, Bibliotecário e Administrador.

Sessão: A classe SessaoUsuario mantém informações do usuário logado durante toda a execução da aplicação.

2. Gerenciamento de Empréstimos

Selecionar usuário
Escolher exemplar disponível
Definir data de devolução prevista
Registrar empréstimo (transação)
Atualizar status do exemplar para "Emprestado"

3. Devolução de Livros

Processamento de Devolução: Registra a data de devolução, calcula dias de atraso e atualiza o status do exemplar para "Disponível". Se houver atraso, gera multa automaticamente.

4. Status de Exemplares

Disponível
Pronto para empréstimo
Emprestado

Reservado
Aguardando devolução
Indisponível

Manutenção
Em reparo

5. Controle de Atrasos e Multas

Sistema de Multas: Calculadas automaticamente quando há atraso na devolução.
Parâmetros configuráveis:

  • ValorEmprestimoExterno: R$ 5,00
  • MultaDiaria: R$ 2,00 por dia de atraso

Tabelas Principais

Chave, Valor, Descricao

Configurações globais do sistema (multas, valores, etc).

Constraints e Índices

✓ Índice Único: Um exemplar só pode ter um empréstimo aberto por vez (UX_Emprestimos_ExemplarAberto)

✓ Índice de Período: Otimização de buscas de reservas por espaço e data (IX_ReservasEspaco_Espaco_Periodo)

✓ Validações: Check constraints em várias tabelas para garantir integridade de dados (perfis, tipos, status, etc)

🔄 Fluxo de Funcionamento

Inicialização da Aplicação

Program.Main() executa
DatabaseInitializer.Inicializar() verifica banco
Cria banco "SGB" se não existir
Executa schema.sql (criação de tabelas)
Cria usuário admin padrão se necessário
Exibe FrmLogin para autenticação

Fluxo de Login

Usuário insere email e senha
Consulta banco de dados (tabela Usuarios)
Valida hash BCrypt da senha
SessaoUsuario.Iniciar() armazena dados da sessão
Abre FrmPrincipal com permissões de perfil

Fluxo de Empréstimo

Acessa "Realizar Empréstimo"
Seleciona usuário e exemplar disponível
Define prazo de devolução
Sistema executa em TRANSAÇÃO (Begin, Commit, Rollback)
Insere registro em Emprestimos
Atualiza exemplar para status "Emprestado"
Exemplar desaparece da lista de disponíveis

🔒 Segurança

Autenticação

✓ BCrypt Hash: Senhas são armazenadas em hash BCrypt, não em texto plano

✓ SQL Injection Protection: Uso de SqlParameter para todas as consultas

Autorização

⚠ Controle de Acesso: Baseado em perfil do usuário (Usuário, Bibliotecário, Administrador)

Formulários de gerenciamento só são visíveis para Bibliotecários e Administradores

Integridade de Dados

✓ Transações: Operações críticas (como empréstimos) executam em transação ACID

✓ Foreign Keys: Relacionamentos entre tabelas mantidos no banco

💼 Fluxos de Negócio

Fluxo 1: Novo Usuário Realiza Empréstimo

Usuário faz login com suas credenciais
Acessa "Realizar Empréstimo" (se bibliotecário)
Seleciona usuário que pegará o livro
Escolhe exemplar disponível
Define data de devolução (padrão: 7 dias)
Sistema confirma a operação

Fluxo 2: Usuário Verifica Seus Empréstimos

Usuário faz login
Clica em "Meus Empréstimos"
Visualiza tabela com todos seus empréstimos
Pode filtrar por: Todos, Em aberto, Atrasados, Devolvidos
Vê status de cada livro e prazos

Fluxo 3: Devolução com Possível Multa

Bibliotecário acessa "Devoluções"
Localiza empréstimo a devolver
Sistema registra data de devolução
Calcula dias de atraso automaticamente
Se atrasado: gera multa (R$ 2.00/dia)
Exemplar retorna para status "Disponível"

O SGB é um sistema bem estruturado de gestão de biblioteca desenvolvido em .NET 9 com Windows Forms. Ele implementa funcionalidades essenciais como:

  • Autenticação segura com BCrypt
  • Gerenciamento completo de empréstimos e devoluções

O projeto demonstra boas práticas de segurança e possui um banco de dados bem modelado. É uma solução pronta para uso em uma biblioteca de pequeno a médio porte.
